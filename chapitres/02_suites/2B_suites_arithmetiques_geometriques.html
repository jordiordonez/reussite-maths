Cours

Tout ce qui suit est au programme de Première (BO 2019). Les quatre démonstrations encadrées en violet sont exigibles : il faut savoir les refaire.

1Suite arithmétique : on ajoute toujours le même nombre

Définition Une suite \((u_n)\) est arithmétique de raison \(r\) si, pour tout entier \(n\) : \(u_{n+1} = u_n + r\).
Chaque terme s'obtient en ajoutant le même nombre \(r\) au précédent (\(r\) peut être négatif).

Exemple. \(u_0 = 5\), \(r = 3\) : \(5,\ 8,\ 11,\ 14,\ 17,\ \dots\) — on ajoute 3 à chaque fois.
Exemple. Une salle de cinéma vend 200 places le premier jour et 15 de moins chaque jour : \(u_0 = 200\), \(r = -15\) : \(200,\ 185,\ 170,\ \dots\)

Terme général \(u_n = u_0 + n\,r\)    et plus généralement   \(u_n = u_p + (n-p)\,r\).

Avec \(u_0 = 5\), \(r = 3\) : \(u_{10} = 5 + 10\times 3 = 35\). Si on connaît \(u_4 = 17\) : \(u_{10} = 17 + (10-4)\times 3 = 35\). Même résultat.

Démonstration à savoir refaire — terme général d'une suite arithmétique

On écrit les relations de récurrence successives et on les ajoute membre à membre :

\[u_1 = u_0 + r,\quad u_2 = u_1 + r,\quad \dots,\quad u_n = u_{n-1} + r\]

En additionnant, tous les \(u_1, u_2, \dots, u_{n-1}\) apparaissent des deux côtés et se simplifient : il reste \(u_n = u_0 + n\,r\) (le nombre \(r\) a été ajouté \(n\) fois, une fois par relation).

Pour la version avec \(u_p\) : on part de \(u_{p+1} = u_p + r\) jusqu'à \(u_n = u_{n-1} + r\) ; il y a \(n-p\) relations, donc \(u_n = u_p + (n-p)\,r\).

Lien avec les fonctions affines \(u_n = r\,n + u_0\) est de la forme \(f(n) = a n + b\) avec \(a = r\) et \(b = u_0\). Les points \((n\,;u_n)\) sont donc alignés sur une droite de coefficient directeur \(r\) : c'est une croissance linéaire.

2Suite géométrique : on multiplie toujours par le même nombre

Définition Une suite \((u_n)\) est géométrique de raison \(q\) si, pour tout entier \(n\) : \(u_{n+1} = q\,u_n\).
Chaque terme s'obtient en multipliant le précédent par le même nombre \(q\) (\(q\ne 0\)).

Exemple. \(u_0 = 3\), \(q = 2\) : \(3,\ 6,\ 12,\ 24,\ 48,\ \dots\) — on double à chaque fois.
Exemple. \(u_0 = 80\), \(q = \tfrac12\) : \(80,\ 40,\ 20,\ 10,\ 5,\ \dots\)

Terme général \(u_n = u_0\,q^{\,n}\)    et plus généralement   \(u_n = u_p\,q^{\,n-p}\).

Avec \(u_0 = 3\), \(q = 2\) : \(u_{10} = 3\times 2^{10} = 3\times 1024 = 3072\). Si on connaît \(u_3 = 24\) : \(u_{10} = 24 \times 2^{7} = 24\times 128 = 3072\).

Démonstration à savoir refaire — terme général d'une suite géométrique

Même idée qu'au point 1, mais on multiplie les relations :

\[u_1 = q\,u_0,\quad u_2 = q\,u_1,\quad \dots,\quad u_n = q\,u_{n-1}\]

Le produit membre à membre donne \(u_1 u_2 \cdots u_n = q^{\,n}\, u_0 u_1 \cdots u_{n-1}\). Si les termes sont non nuls, on simplifie par \(u_1 u_2\cdots u_{n-1}\) : \(u_n = q^{\,n} u_0\). Le facteur \(q\) a été appliqué \(n\) fois.

De \(u_p\) à \(u_n\), on applique \(q\) exactement \(n-p\) fois : \(u_n = u_p\,q^{\,n-p}\).

Lien avec les évolutions à taux constant Augmenter de \(t\,\%\) revient à multiplier par \(q = 1 + \dfrac{t}{100}\) ; diminuer de \(t\,\%\), à multiplier par \(q = 1 - \dfrac{t}{100}\).
Capital à 3 % par an : \(C_0 = 1000\) €, \(q = 1{,}03\), donc \(C_n = 1000\times 1{,}03^{\,n}\). Au bout de 10 ans : \(C_{10} \approx 1343{,}92\) €.
Baisse de 5 % : \(q = 0{,}95\) (et non \(-0{,}05\) !). Les points \((n\,;u_n)\) ne sont plus alignés : c'est une croissance exponentielle.

3Somme des premiers entiers et somme arithmétique

Formule \[1 + 2 + 3 + \dots + n = \frac{n(n+1)}{2}\]

\(1 + 2 + \dots + 100 = \dfrac{100\times 101}{2} = 5050\).

Démonstration à savoir refaire — \(1+2+\dots+n\)

On note \(S = 1 + 2 + \dots + n\) et on l'écrit dans les deux sens, puis on ajoute colonne par colonne :

\[\begin{array}{rcl} S &=& 1 + 2 + \dots + (n-1) + n \\ S &=& n + (n-1) + \dots + 2 + 1 \\ \hline 2S &=& (n+1) + (n+1) + \dots + (n+1) \end{array}\]

Chaque colonne vaut \(n+1\) et il y a \(n\) colonnes : \(2S = n(n+1)\), donc \(S = \dfrac{n(n+1)}{2}\).

Somme de termes consécutifs d'une suite arithmétique \[S = (\text{nombre de termes})\times\frac{\text{premier terme} + \text{dernier terme}}{2}\] Par exemple \(u_0 + u_1 + \dots + u_n = (n+1)\times\dfrac{u_0 + u_n}{2}\).

Exemple. \(u_n = 5 + 3n\). Calculer \(u_3 + u_4 + \dots + u_{10}\) : il y a \(10 - 3 + 1 = 8\) termes, \(u_3 = 14\), \(u_{10} = 35\), donc \(S = 8\times\dfrac{14+35}{2} = 8\times 24{,}5 = 196\).

Pourquoi ça marche : la même astuce « écrire dans les deux sens » ; chaque colonne vaut \(u_{\text{premier}} + u_{\text{dernier}}\).

4Somme des puissances et somme géométrique

Formule (pour \(q \ne 1\)) \[1 + q + q^2 + \dots + q^n = \frac{1 - q^{\,n+1}}{1 - q}\]

\(1 + 2 + 4 + \dots + 2^{10} = \dfrac{1 - 2^{11}}{1 - 2} = \dfrac{1 - 2048}{-1} = 2047\).   (Si \(q = 1\), la somme vaut simplement \(n+1\).)

Démonstration à savoir refaire — \(1+q+\dots+q^n\)

On note \(S = 1 + q + q^2 + \dots + q^n\) et on calcule \(qS\) :

\[qS = q + q^2 + \dots + q^n + q^{\,n+1}\]

En soustrayant, presque tout se simplifie (« télescopage ») : \(S - qS = 1 - q^{\,n+1}\), soit \((1-q)S = 1 - q^{\,n+1}\).

Comme \(q \ne 1\), on divise par \(1-q\) : \(S = \dfrac{1-q^{\,n+1}}{1-q}\).

Somme de termes consécutifs d'une suite géométrique \[S = \text{premier terme}\times\frac{1 - q^{\,\text{nombre de termes}}}{1 - q}\] Par exemple \(u_0 + u_1 + \dots + u_n = u_0\,\dfrac{1 - q^{\,n+1}}{1-q}\) (on met \(u_0\) en facteur).

Exemple. \(u_n = 3\times 2^n\). \(u_0 + \dots + u_5 = 3\times\dfrac{1-2^6}{1-2} = 3\times 63 = 189\). Vérification : \(3+6+12+24+48+96 = 189\). ✓

5Sens de variation

Arithmétique

\(u_{n+1} - u_n = r\), donc :
  • \(r > 0\) : croissante
  • \(r < 0\) : décroissante
  • \(r = 0\) : constante

Géométrique, \(u_0 > 0\)

\(u_{n+1} - u_n = u_0\,q^{\,n}(q-1)\), donc :
  • \(q > 1\) : croissante
  • \(0 < q < 1\) : décroissante
  • \(q = 1\) : constante
  • \(q < 0\) : ni l'un ni l'autre (signes alternés)

Exemples. \(u_n = 200 - 15n\) est décroissante (\(r = -15 < 0\)). \(C_n = 1000\times 1{,}03^n\) est croissante (\(q = 1{,}03 > 1\)). \(v_n = 80\times 0{,}5^n\) est décroissante. \(w_n = (-2)^n = 1, -2, 4, -8, \dots\) n'est ni croissante ni décroissante.

Si \(u_0 < 0\), les variations d'une suite géométrique sont inversées : \(u_n = -5\times 2^n\) est décroissante.

6Intuition de limite (sans formalisme)

Comportement de \(q^n\) quand \(n\) devient grand
  • Si \(0 < q < 1\) : \(q^n\) se rapproche de \(0\). Exemple : \(0{,}5^{10} \approx 0{,}001\), \(0{,}9^{50}\approx 0{,}005\).
  • Si \(q > 1\) : \(q^n\) dépasse n'importe quel nombre, on dit qu'il tend vers \(+\infty\). Exemple : \(1{,}03^{100} \approx 19{,}2\), \(2^{30}\) dépasse un milliard.
  • Si \(q = 1\) : \(q^n = 1\) pour tout \(n\).

Conséquence : une suite arithmétique de raison \(r > 0\) et une suite géométrique de raison \(q > 1\) finissent toutes deux par dépasser tout seuil, mais la géométrique le fait beaucoup plus vite : avec \(u_n = 5 + 3n\) et \(v_n = 3\times 2^n\), \(u_{20} = 65\) alors que \(v_{20} = 3\,145\,728\).

Aucune formalisation en Première : on observe, on conjecture. La définition rigoureuse de la limite et l'étude complète de \((q^n)\) sont au programme de Terminale (fiche 2C).

Méthode

AReconnaître une suite arithmétique ou géométrique

  1. Calculer \(u_{n+1} - u_n\) pour tout \(n\) (avec l'expression générale, pas seulement sur trois valeurs). Si le résultat est une constante \(r\) : arithmétique de raison \(r\).
  2. Sinon, calculer \(\dfrac{u_{n+1}}{u_n}\). Si c'est une constante \(q\) : géométrique de raison \(q\).
  3. Sinon, la suite n'est ni l'une ni l'autre ; un contre-exemple numérique suffit pour le prouver.
Exemple 1 \(u_n = 7 - 4n\). \(u_{n+1} - u_n = 7 - 4(n+1) - (7 - 4n) = -4\). Arithmétique, \(r = -4\), \(u_0 = 7\).
Exemple 2 \(v_n = 5\times 3^{n+1}\). \(\dfrac{v_{n+1}}{v_n} = \dfrac{5\times 3^{n+2}}{5\times 3^{n+1}} = 3\). Géométrique, \(q = 3\), \(v_0 = 15\).
Contre-exemple \(w_n = n^2\) : \(w_0 = 0, w_1 = 1, w_2 = 4\). \(w_1 - w_0 = 1\) mais \(w_2 - w_1 = 3\) : pas arithmétique. \(w_1/w_0\) n'existe même pas : pas géométrique.

BTrouver le terme général

  1. Identifier la nature (méthode A) et la raison.
  2. Repérer le terme connu : est-ce \(u_0\) ? \(u_1\) ? \(u_p\) ?
  3. Appliquer \(u_n = u_p + (n-p)\,r\) ou \(u_n = u_p\,q^{\,n-p}\).
Exemple Suite géométrique de raison \(q = 3\) avec \(u_2 = 18\). Alors \(u_n = 18\times 3^{\,n-2}\). Pour revenir à \(u_0\) : \(u_0 = 18/9 = 2\), donc aussi \(u_n = 2\times 3^n\).

CCalculer une somme de termes consécutifs

  1. Compter le nombre de termes : de \(u_a\) à \(u_b\), il y en a \(b - a + 1\).
  2. Arithmétique : \(S = N\times\dfrac{u_a + u_b}{2}\). Calculer d'abord \(u_a\) et \(u_b\).
  3. Géométrique : \(S = u_a\times\dfrac{1 - q^{N}}{1 - q}\).
  4. Vérifier l'ordre de grandeur (par exemple avec les deux ou trois premiers termes).
Exemple \(u_n = 2\times 3^n\), calculer \(u_2 + u_3 + \dots + u_6\). Nombre de termes : \(6 - 2 + 1 = 5\). \(u_2 = 18\). \(S = 18\times\dfrac{1-3^5}{1-3} = 18\times\dfrac{-242}{-2} = 18\times 121 = 2178\).

DModéliser une évolution à taux fixe

  1. Traduire le taux en coefficient multiplicateur : \(+t\,\% \Rightarrow q = 1 + \frac{t}{100}\) ; \(-t\,\% \Rightarrow q = 1 - \frac{t}{100}\).
  2. Poser \(u_0\) = valeur initiale (année de départ = rang 0) et \(u_{n+1} = q\,u_n\).
  3. Conclure : \(u_n = u_0\,q^n\), puis calculer ce qui est demandé.
Exemple Une ville de 20 000 habitants gagne 2 % par an. \(q = 1{,}02\), \(u_n = 20\,000\times 1{,}02^n\). Dans 15 ans : \(u_{15}\approx 26\,917\) habitants.
Accroissement constant Si au contraire la ville gagne 400 habitants par an (et non 2 %), la suite est arithmétique : \(u_n = 20\,000 + 400 n\).

EChercher un seuil (algorithme)

« À partir de quel rang \(u_n\) dépasse-t-il \(S\) ? » En Première, on n'utilise pas le logarithme : on calcule les termes jusqu'à dépasser le seuil, à la main (tableau) ou avec une boucle while.

u = 20000      # u_0
n = 0
while u <= 30000:
    u = u * 1.02
    n = n + 1
print(n)       # premier rang tel que u_n > 30000

Ici l'algorithme affiche 21 : \(u_{20}\approx 29\,719 < 30\,000\) et \(u_{21}\approx 30\,313 > 30\,000\). Toujours justifier avec les deux valeurs qui encadrent le seuil.

Attention à la condition : while u <= S s'arrête au premier rang où \(u_n > S\) ; la suite doit être croissante pour que cela ait un sens.

!Erreurs fréquentes

Nombre de termes De \(u_3\) à \(u_{10}\), il y a \(10 - 3 + 1 = 8\) termes, pas 7. Compter sur un exemple court : de \(u_3\) à \(u_5\), on a \(u_3, u_4, u_5\) : 3 termes, et \(5-3+1 = 3\).
Premier terme \(u_n = u_0\,q^n\) et non \(u_1\,q^n\). Si la suite commence à \(u_1\), alors \(u_n = u_1\,q^{\,n-1}\).
Taux négatif Une baisse de 5 % donne \(q = 0{,}95\), pas \(q = -0{,}05\) ni \(q = -5\).
Confusion \(+\) / \(\times\) « augmente de 300 par an » : arithmétique ; « augmente de 3 % par an » : géométrique.
Formule de somme \(\dfrac{1-q^{N}}{1-q}\) avec \(N\) = nombre de termes, pas le dernier indice. \(u_0 + \dots + u_n\) a \(n+1\) termes, donc l'exposant est \(n+1\).
