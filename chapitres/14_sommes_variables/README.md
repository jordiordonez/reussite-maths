## Points d'attention issus du texte officiel

- La linéarité de l'espérance vaut pour des variables **quelconques**. L'additivité de la variance exige l'**indépendance**. Confondre les deux est la faute centrale du chapitre.
- Le programme précise que l'indépendance est toujours envisagée dans le cadre d'une succession d'épreuves indépendantes : **justifier l'indépendance de variables données a priori est hors programme**.
- L'additivité de la variance est **admise**. La relation sur l'espérance d'un produit n'est pas un attendu.
- Le texte demande explicitement de faire remarquer que l'inégalité de Bienaymé-Tchebychev est **loin d'être optimale** : elle majore par un quart une probabilité que la simulation montre souvent inférieure à cinq centièmes. C'est un point de compréhension, pas une réserve.
