### Cours et méthode

**Tous les exemples numériques ont été recalculés symboliquement avec sympy** (script dédié, 40 vérifications) : chaque \(F\) annoncée a été dérivée et comparée à la \(f\) annoncée. **0 énoncé faux.** Le détail :

- cours 1 : \(\left(x^{2}+k\right)' = 2x\) ;
- cours 2 : \(\left(x^{3}\right)'\), \(\left(x^{3}+7\right)'\), \(\left(x^{3}-2\right)'\) ;
- cours 5, les **onze lignes** du tableau de référence : constante, \(x\), \(x^{n}\) pour \(n = 0\ldots7\), \(\tfrac{1}{x^{2}}\), \(x^{n}\) pour \(n = -2,-3,-4,-5\), \(\tfrac1x \to \ln x\) **et** \(\tfrac1x \to \ln(-x)\) (dérivée vérifiée : \(\tfrac{-1}{-x} = \tfrac1x\)), \(\mathrm e^{x}\), \(\cos \to \sin\), \(\sin \to -\cos\), \(\tfrac{1}{2\sqrt x} \to \sqrt x\) ; plus les trois exemples de lecture (\(x^{4}\), \(\tfrac{1}{x^{3}}\), \(\sin\)) ;
- cours 6, les **cinq lignes** de formes composées et leurs cinq exemples (\(2x(x^{2}+3)^{4}\), \(\tfrac{2x}{x^{2}+1}\), \(2x\mathrm e^{x^{2}}\), \(\tfrac{1}{2\sqrt{x+5}}\), \(\tfrac{2x}{(x^{2}+1)^{2}}\)), puis les trois exemples de compensation (\(x\mathrm e^{x^{2}}\), \(\mathrm e^{5x}\), \((2x+1)^{3}\)) ;
- cours 7 : \(F(x) = x^{3}-2x^{2}+6\) — dérivée vérifiée **et** \(F(1) = 5\) vérifié, ainsi que l'étape intermédiaire \(G(1) = -1\) ;
- méthode C : \(\tfrac12\ln(x^{2}+4)\) et \(-2\mathrm e^{-2x}\) ;
- méthode D : \(-\tfrac2x + 4\), avec \(G(2) = -1\) et \(F(2) = 3\) ;
- méthode E : \(\tfrac13\mathrm e^{3x}\) **et** le contre-exemple, où il a été vérifié que \(\left(3\mathrm e^{3x}\right)' = 9\mathrm e^{3x}\) — c'est-à-dire que l'erreur montrée est bien une erreur ;
- erreurs fréquentes : \(\tfrac{x^{3}}{3}\) pour \(x^{2}\), \(\left(\tfrac{x^{4}}{4}\right)' = x^{3}\) (donc le produit des primitives est bien faux), \(\tfrac{(3x+1)^{5}}{15}\) pour \((3x+1)^{4}\) **et** la vérification que \(\tfrac{(3x+1)^{5}}{5}\) ne convient pas, \(\tfrac{x^{4}}{4}\) pour \(x^{3}\).

Les énoncés de théorème ont été contrôlés hypothèse par hypothèse : le mot **intervalle** figure dans les trois théorèmes (existence, structure de l'ensemble des primitives, condition initiale) ; la démonstration exigible du cours 4 est faite **dans les deux sens** (toute \(F+k\) convient ; toute primitive est de cette forme) et s'appuie uniquement sur « dérivée nulle sur un intervalle ⟹ constante », résultat de Première présent en 3C ; le contre-exemple sur \(\left]-\infty\,;0\right[ \cup \left]0\,;+\infty\right[\) justifie l'hypothèse. L'unicité du cours 7 est démontrée par équivalence (\(k = y_0 - G(x_0)\), valeur unique).
